# DSI-pictochat
an DSI picochat decompilation, in which all code is reverse engineered slowly one by one.
this decompilation is an effort to take all of the code and decompille it to see how the app works etc
# why no .nds file?
because distrubuting .nds roms in an repository is pretty much 'Illegal' and is asking to get sued, thus why to build this, you must dump your own assets from an legally gained copy of the DSI pictochat which any nintendo DSI has installed by default.
